# Security

diskmap deletes files and can run with administrator rights, so problems that could make it delete the
wrong thing or be abused by another program matter a lot.

## Reporting a problem

Please report security issues privately through GitHub: open the **Security** tab of this repository and
choose **Report a vulnerability**. Don't open a public issue for them.

Useful details: what you did, what diskmap deleted or tried to delete, the version (Settings → About),
and whether it was running as administrator.

## Supported versions

Only the latest release gets fixes. The installed and portable versions update themselves from GitHub
Releases unless updates are turned off in Settings.
